# Changelog

Этот файл ведётся на русском языке и фиксирует заметные изменения в прошивке грелки `iHeater-link` (ESP-линк нагревателя).

История до этого файла — в git-тегах (последний выпущенный: `v1.0.1`).

## Типы изменений

- **Добавлено** — для новых функций.
- **Изменено** — для изменений в существующей функциональности.
- **Устарело** — для функций, которые скоро будут удалены.
- **Удалено** — для удалённых на данный момент функций.
- **Исправлено** — для любых исправлений багов.
- **Безопасность** — на случай уязвимостей.

## [Не выпущено]

### Добавлено

- Игнор внешних команд («Игнор. внеш. команды») → SDK-гейт.
- OTA-обновление прошивки ESP по воздуху (`OtaReceiver`, self-update). STM32 нагревателя air-gapped — по воздуху не обновляется.
- Переход на `MenuPublisher`; общий header `menu_commands`.
- Роль для температуры нагрева; `chamberTemp` из активной интеграции; прогресс Bambu в `status`.
- Ограничение мощности WiFi (8.5 dBm на esp32c3 super-mini).

### Изменено

- Миграция на `menu_protocol_v1`, удалены legacy-обработчики команд.
- Режим `Drying → Heating` (Phase 5).
- Переименование capability-флагов (`hasHeater/hasFan/hasWeight`); `timestamp` в публикации отключён.

### Исправлено

- Маппинг `ERRSEV_CRITICAL` → `EventKind::Critical`.
